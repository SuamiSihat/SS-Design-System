SSCAM

SuamiSihat™ Creative Assets Management — purpose-built Windows desktop application.

SSCAM v2.1

Windows Only (WPF .NET Framework / .NET 8)

SSCAM (SuamiSihat™ Creative Assets Management) is the official Windows desktop application for internal staff, media teams, and clinic staff. It streamlines asset management, automated brand watermarking, photo/video capture, color preset grading, and one-click cloud/NAS sync.

SSCAM — SuamiSihat™ Creative Assets Management (Windows Desktop App)
─ □ ✕
  • Windows-only WPF desktop application built for high performance
  • On-brand colour grading presets — matches SuamiSihat™ visual identity
  • Auto-watermark with approved logo placement & safe zones
  • Export directly to approved formats (WebP, AVIF, MP4 H.265)
  • Batch processing — apply brand filters to entire media shoots
  • Privacy mode — automatic face blurring for patient content
  • One-click upload to SSNAS shared drive & cloud storage
