Microsoft Fluent 2 Guidelines & UX Framework

SuamiSihat's design system strictly adopts Microsoft's Fluent 2 design language adapted to our brand palette. Grounded in 4 core principles, 8 design dimensions, and a unified UX state framework.

1. Natural

Feels intuitive and responsive. Smooth spring motion curves, organic wave motion, and fluid interactive feedback matching human touch.

2. Inclusive

Built for everyone. Strict WCAG 2.1 AA/AAA contrast ratios, keyboard accessibility, focus rings, and high-contrast dark mode support.

3. Effortless

Reduces cognitive load. Clean visual hierarchy, predictable component states, clear action targets (44px min), and contextual tokens.

4. Intentional

Every detail has a purpose. Single source-of-truth tokens across Web and Expo React Native, with consistent component contracts.

Fluent 2 System Dimensions Summary
fluent2.microsoft.design
Material & Surfaces

Uses Acrylic (20px blur + 180% saturation) for floating navigation bars and modals, and Mica (base layer opacity) for subtle hierarchy layering without distracting reflections.

Elevation & Depth

6 elevation tiers (2, 4, 8, 16, 28, 64) cast directional ambient shadows. Interactive elements elevate dynamically on hover (`translateY(-4px)` + brand shadow tint).

Iconography

Standardized on Fluent UI System Icons (Regular style). Standard sizes: 16px (inline), 20px (menu/button), 24px (nav/headers), 32px/48px (feature displays).

Layout & Grid

Strict 4px base grid (`--f-space-1` to `--f-space-24`). All touchable interactive elements adhere to a 44px minimum hit target for mobile accessibility.

Motion & Curves

Entering items use Decelerate Curve (`cubic-bezier(0.1, 0.9, 0.2, 1.0)`), exit items use Accelerate, and hover feedback uses tactile Spring easing.

Shapes & Radii

8 corner radius scale options: `sm` (4px), `md` (8px), `lg` (12px), `xl` (16px), `2xl` (20px), `3xl` (28px), and `full` (9999px pill). Radii are never mixed within a single component tree.

Fluent 2 Component State Matrix
UX Framework
State Visual Response Cursor & Accessibility
Rest Base surface background, `--f-shadow-2` elevation, standard border stroke. Pointer / Default cursor.
Hover Surface brightens to `--color-neutral-bg-4`, elevates with `--f-shadow-brand-sm` and `translateY(-2px)`. Pointer cursor with spring motion transition.
Pressed / Active Tactile scale down (`scale(0.97)`), background darkens, ripple animation triggers. Active touch feedback.
Focused 2px dual-ring focus outline (`outline: 2px solid var(--color-brand-primary)` + offset). Keyboard navigation indicator (`:focus-visible`).
Disabled Opacity reduced to `0.38`, background flattened, shadows removed. `cursor: not-allowed;` with `aria-disabled="true"`.
