Installation Guide by Email Client
  1. Click "Copy Formatted Signature (Clipboard)" above.
  2. Open Microsoft Outlook → go to File → Options → Mail → Signatures... (or Outlook Settings → Accounts → Signatures on Web).
  3. Create a new signature, click in the edit body box, and press Ctrl+V (Windows) or Cmd+V (Mac) to paste.
  4. Select your new signature for "New messages" and "Replies/forwards". Save and close.
  1. Click "Copy Formatted Signature (Clipboard)" above.
  2. Open Gmail in your web browser → click the gear icon ⚙ → See all settings.
  3. Scroll down to the Signature section → click + Create new.
  4. Paste (Ctrl+V / Cmd+V) into the text editor box.
  5. Set Signature defaults to your new signature and click Save Changes at the bottom of the page.
  1. Click "Copy Formatted Signature (Clipboard)" above.
  2. Open Apple Mail on macOS → Mail → Settings (Preferences) → Signatures.
  3. Choose your email account and click + to add a signature.
  4. Uncheck "Always match my default message font", then paste (Cmd+V) into the preview box.
