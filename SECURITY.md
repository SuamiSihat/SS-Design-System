# Security Policy

## Supported Versions

We actively issue security updates and patches for the following versions of the SuamiSihat™ Design System:

| Version | Supported          |
| ------- | ------------------ |
| 3.5.x   | :white_check_mark: |
| 3.4.x   | :white_check_mark: |
| 3.2.x   | :white_check_mark: |
| < 3.2   | :x:                |

## Reporting a Vulnerability

The SuamiSihat™ team takes security seriously. If you discover a potential security vulnerability, please **do not create a public issue or disclosure**.

Instead, please send a report directly to our security team:
- **Email**: [branding@suamisihat.com](mailto:branding@suamisihat.com)
- **Response SLA**: 24–48 hours

Please include:
- A detailed description of the vulnerability
- Steps or proof-of-concept to reproduce the issue
- Potential impact assessment

We appreciate your effort in responsibly disclosing security findings.
