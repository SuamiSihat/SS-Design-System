SuamiSihat™ Brand Guidelines

The core standards governing visual hierarchy, typography neutrality, logo pairing, and medical copywriting across all patient touchpoints.

RULE 1

The 60:30:10 Visual Allocation Standard

Every digital and physical interface must strictly enforce the 60:30:10 color ratio to maintain clinical cleanliness and eliminate patient visual fatigue.

60% Foundation Canvas

Canvas Light (#F8FAFC) and Surface White (#FFFFFF). Creates open breathing room, clinical hygiene, and calm readability.

30% Structural Trust

Prussian Blue (#022057) and SS Blue (#043388). Organizes layout headers, navigation bars, cards, and corporate footer anchors.

10% Primary Conversion Accent

Azure Blue (#21A1F7) & Banana Yellow (#F7E143). Strictly reserved for dominant patient conversion CTAs (e.g. "BOOK APPOINTMENT").

RULE 2

Strict Neutral Typography Standard (#1C1C1C)

Body text, labels, and headings on light backgrounds must strictly use Neutral Black (#1C1C1C). Pure black (#000000) causes excessive contrast vibration on high-DPI displays and is strictly prohibited for typography.

✅ CORRECT
color: #1C1C1C; /* var(--ss-neutral-black) */
❌ PROHIBITED
color: #000000; /* Causes harsh ocular glare */
CSS Typography Token Standard 
body, h1, h2, h3, h4, h5, h6, p, label, .f-text {
  color: var(--color-neutral-fg-1, #1C1C1C);
  font-family: var(--f-font-family-base, 'Inter', -apple-system, sans-serif);
}
RULE 3

Elimination of CTA Competition

Secondary cards, filter pills, and navigation links must never use solid high-chroma accent fills. Only the single primary patient intent on a page receives the vibrant 10% Accent CTA.
