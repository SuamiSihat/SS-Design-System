# Claims review notes (staff only)

Moved out of `static/products/*/metadata.json` so they are not served to the public site. Regulatory reviews these before any brand PDF ships.

## ANDROLAB

Earlier copy named a prescription medicine (tadalafil) under ANDROLAB RX. Prescription medicines cannot be advertised to the public in Malaysia; keep RX content internal to clinic materials.

## Dr Mit Ring®

Path A: the product stays a condom accessory. Never publish erection, hardness, stamina, ejaculation timing, venous leakage or 'no side effects' claims, 'Andrologically tested', 'patented' or 'clinically proven', or any doctor's name or photo. The current box badges and leaflet benefits are being removed in the next print run.

## Mensculine

Ingredient and effect statements must follow each export market's cosmetic rules.

## MENSS

Device descriptions such as 'medical-grade' or 'vascular rehabilitation' need registration evidence before public use.

## nuCaffe®

Use Physta® benefit wording only as approved by the ingredient licensor.

## REJAL

Never publish: 'melancarkan darah', 'tenaga batin', immunity, cardiovascular, digestive or nitric-oxide benefits, 'organic', lab values (TPC, diastase, SAC %). Describe ingredients, origin and use only. Every label needs kcal/kJ nutrition, a real serving size, net weight, the infant warning on honey, and Halal/MeSTI only from that manufacturer's own valid certificate.
